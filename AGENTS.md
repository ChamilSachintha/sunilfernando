# Project Git Commit Rules

- Every time a change is made in the project, immediately commit that change locally with a clear, relevant commit message.
- When making multiple distinct changes, commit each logical change separately with its own descriptive commit message rather than bundling all changes into a single commit.
- Do not push commits to the remote repository unless explicitly asked by the user.
